# Zhen Wang · Academic Homepage

GitHub Pages repository for WangZhen-Hebut. Edit the biography, research interests and contact details in `index.md`, and sidebar details in `_config.yml`.

News and Publications show the six latest eligible works from `_data/publications.yml`. Set `rank` to `CCF A` or `CCF B` for an eligible conference paper, or `CAS 1` or `CAS 2` for an eligible journal article. Use `[venue]` in the `news` sentence for the highlighted venue name. Keep one entry per work. Set `published` to the quoted ISO publication date (YYYY-MM or YYYY-MM-DD) and `date_label` to its displayed month and year. Use `image` for a paper figure and `figure_caption` for its description. For an arXiv-only work, set `preprint: true`. Update the same entry when the final version appears.

The English layout uses the supplied Minimal Light template. Open `html_source_file/index.html` for a local preview of this edition. GitHub Pages builds from the repository root; the preview directory is excluded from publication. The layout and theme are credited to [Minimal Light](https://github.com/yaoyao-liu/minimal-light).
